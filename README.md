# ALT State

This repository has been moved to GitHub: https://github.com/tania-krauch/ALT-State--25

Quick start

- Install dependencies:

```powershell
npm install
```

- Run development server:

```powershell
npm run dev
```

- Build for production:

```powershell
npm run build
```

- Preview production build:

```powershell
npm run preview
```

Deploy to GitHub Pages

```powershell
npm run deploy
```

Notes

- Vite `base` is set to `/ALT-State--25/` to support GitHub Pages routing.
- Update the `repository` field in `package.json` if the GitHub owner or repo name changes.
- If you don't want `gh-pages`, remove the `deploy` scripts and the `gh-pages` devDependency.
